# PPT 生成提示词

请根据以下项目资料生成一份 6-8 页中文技术面试展示 PPT 大纲。要求：

1. 目标是帮助候选人快速讲清项目，适合实习面试展示。
2. 不要卡在完整复现实验；没有指标时，用实验设计、工程产出和失败定位替代。
3. 每页给出标题、三到五个要点、建议配图或表格。
4. 风格适合计算机行业实习面试，重点讲问题、架构/方法、代码流程、改造点和后续计划。
